# Image2Pro

通过上游 `/v1/models` 动态导入图片和视频模型。同一套公开生成协议下新增型号无需修改插件中的模型列表；新增接口或参数仍需按上游文档扩展。

## 获取模型

更新后端并重启，启用 Image2Pro 任务插件，将任务插件渠道绑定到 `image2pro`。默认地址为 `https://api.image2pro.top/v1`，密钥填写在渠道密钥栏。若配置了自定义插件覆盖，需同步更新覆盖源码。

在渠道中点击「获取模型」并保存选择。目录按 `metadata.type` 导入 `image` 和 `video`，渠道模型名直接使用上游 ID：

| 目录类型 | 客户端名称                  | 生成接口                      |
| -------- | --------------------------- | ----------------------------- |
| `image`  | `<上游 ID>`                  | `/v1/images/tasks`            |
| `video`  | `<上游 ID>`                  | `/v1/videos` 或视频 Responses |

缺少类型或属于其他类型的条目会列入不支持列表。目录读取失败不会用静态列表伪装成功，也不会改写渠道已有选择。旧型号和已保存带前缀映射继续可用；图片与视频分别由请求接口识别。

## 视频参考音频

视频 JSON 请求可携带最多 3 个不重复的参考音频，使用 HTTPS URL 或已上传到供应商的 `mediaId`：

```json
{
  "model": "<上游视频模型 ID>",
  "prompt": "根据参考音频生成视频",
  "duration": 8,
  "ratio": "16:9",
  "audios": ["https://cdn.example/reference.mp3", { "mediaId": "uploaded-audio-id" }]
}
```

插件不上传本地音频文件，不接受音频 Data URL、HTTP URL 或视频参考素材。具体型号是否支持参考音频由上游决定。Responses 继续支持文本及参考图片输入。

## 用量与兼容性

已知 Seedance 按次计费、Flash 按请求秒数计费，图片按请求张数计费；旧任务保留原冻结用量。未知视频型号默认按请求秒数提供用量，新型号仍需在管理后台配置价格。

未知视频型号要求显式提供 1–3600 的整秒时长，参考图最多 9 张；旧 Seedance 和 Flash 保留原型号限制。请求使用公开字段白名单，不透传未知参数。提交保留幂等键和禁止自动重试，避免结果未知时重复生成。

上游文档：[Image2Pro API](https://image2pro.top/api-docs)。本地合成测试覆盖目录导入、精确模型 ID、图片任务生命周期、结算和参考音频校验，不代表真实供应商账号的受理或生成质量验收。
